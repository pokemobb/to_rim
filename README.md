# 📍 โต๊ะวันนี้

แผนที่ 3D ของโรงอาหาร ใช้บอกเพื่อนว่าวันนี้เรานั่งโต๊ะไหน ไม่ต้องใช้ฐานข้อมูล เพราะเลขโต๊ะอยู่ในลิงก์

## ใช้งาน

1. เปิดเว็บ แล้วแตะโต๊ะที่นั่ง (เว็บจะจำโต๊ะของวันนี้ไว้ให้)
2. ใส่ชื่อ (ไม่ใส่ก็ได้) แล้วกด **แชร์ให้เพื่อน** → ส่งเข้า LINE
3. เพื่อนเปิดลิงก์ เช่น `https://<เว็บ>.vercel.app/?t=10-6&d=2026-11-04&n=บอส` จะเห็นหมุดปักที่โต๊ะ 10-6
   ถ้าเป็นลิงก์ของวันก่อน เว็บจะเตือนว่าอาจไม่ใช่โต๊ะของวันนี้

ชื่อโต๊ะคือ `แถว-ตัวที่` เช่น `10-6` = แถว 10 (เลขหัวแถว) ตัวที่ 6 นับจากประตูทางเข้า

## แอดมิน: แก้ผังโต๊ะ

1. เปิด `https://<เว็บ>.vercel.app/?admin`
2. แตะโต๊ะเพื่อเปลี่ยนเป็น **โต๊ะยาว 6 ที่นั่ง** / **โต๊ะจัตุรัส 4 ที่นั่ง**, หมุน 90° หรือลบ
   แตะช่องว่างเพื่อเพิ่มโต๊ะ
   เลือกขอบเขตได้ว่าจะแก้ **โต๊ะนี้**, **ทั้งแถว** (ตามเลขหัวแถว 1–14) หรือ **ตัวที่ N ทุกแถว** — กดทีเดียวแก้ทั้งหมด
   ถ้าแถวมีช่องว่าง จะมีปุ่ม "เติมโต๊ะในช่องว่าง" ให้ด้วย
   กด **ออกจากแอดมิน** ที่มุมบนเพื่อกลับหน้าปกติ (ที่แก้ค้างไว้ยังอยู่ เปิด `?admin` ครั้งหน้าก็ทำต่อได้)
3. ที่แก้จะเก็บไว้ในเครื่องแอดมินเท่านั้น (คนอื่นยังเห็นผังเดิม) จนกว่าจะเผยแพร่
4. กด **ดาวน์โหลด layout.json** แล้วเอาไฟล์ไปแทน `layout.json` ใน GitHub
   (บนเว็บ github.com: เปิด repo → Add file → Upload files → ลากไฟล์ใส่ → Commit)
5. Vercel จะ deploy ใหม่เองในไม่ถึงนาที ทุกคนเห็นผังใหม่

ใครเปิด `?admin` ก็ได้ แต่แก้ได้แค่ในเครื่องตัวเอง จะเผยแพร่จริงได้ต้องมีสิทธิ์ push ขึ้น GitHub repo

ขนาดห้อง ตำแหน่งร้านค้า/ประตู และระยะห่างโต๊ะ แก้ได้ใน `layout.json` โดยตรง (หน่วยเมตร)

- `walls` — แนวกำแพง (ประตูที่อยู่บนแนวกำแพงจะเว้นช่องให้เอง)
- `landmarks` — ของในฉาก ใส่ `kind` เป็น `shop` (ร้านค้า), `dishes` (ที่วางจาน), `toilet` (ห้องน้ำ),
  `door` (ประตู) หรือ `plant` (ต้นไม้) ปกติจะหันหน้าเข้าหากลางห้องเอง ถ้าอยากหมุนเองใส่ `"facing": 90` (องศา)
- หน้าตาของแต่ละแบบอยู่ใน `scenery.js`

## Deploy (GitHub + Vercel)

เป็นเว็บ static ล้วน ไม่มีขั้นตอน build (three.js โหลดจาก CDN)

1. สร้าง repo ใหม่บน GitHub แล้ว push ไฟล์ในโฟลเดอร์นี้ขึ้นไป
2. ที่ vercel.com → **Add New → Project** → เลือก repo นั้น
3. Framework Preset เลือก **Other** ไม่ต้องตั้ง Build Command → กด Deploy
4. หลังจากนี้ push อะไรขึ้น GitHub ก็ deploy ใหม่ให้อัตโนมัติ

## เปิดดูในเครื่อง

ต้องเปิดผ่าน web server (ดับเบิลคลิกไฟล์ตรงๆ ไม่ได้ เพราะใช้ ES modules และโหลด layout.json)

```bash
python3 -m http.server 5173
```

แล้วเปิด http://localhost:5173
