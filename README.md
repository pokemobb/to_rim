# 📍 โต๊ะวันนี้

แผนที่ 3D ของโรงอาหาร ใช้บอกเพื่อนว่าวันนี้เรานั่งโต๊ะไหน ไม่ต้องใช้ฐานข้อมูล เพราะเลขโต๊ะอยู่ในลิงก์

## ใช้งาน

1. เปิดเว็บ แล้วแตะโต๊ะที่นั่ง (เว็บจะจำโต๊ะของวันนี้ไว้ให้)
2. ใส่ชื่อ (ไม่ใส่ก็ได้) แล้วกด **แชร์ให้เพื่อน** → ส่งเข้า LINE
3. เพื่อนเปิดลิงก์ เช่น `https://<เว็บ>.vercel.app/?t=10-6&d=2026-11-04&n=บอส` จะเห็นหมุดปักที่โต๊ะ 10-6
   ถ้าเป็นลิงก์ของวันก่อน เว็บจะเตือนว่าอาจไม่ใช่โต๊ะของวันนี้

ชื่อโต๊ะคือ `แถว-ตัวที่` เช่น `10-6` = แถว 10 (เลขหัวแถว) ตัวที่ 6 นับจากประตูทางเข้า

## แอดมิน: แก้ผังโต๊ะ

1. เปิด `https://<เว็บ>.vercel.app/?admin`
2. แตะโต๊ะเพื่อเปลี่ยนเป็น **โต๊ะยาว 6 ที่นั่ง** / **โต๊ะจัตุรัส 4 ที่นั่ง**, หมุน 90° หรือลบ
   แตะช่องว่างเพื่อเพิ่มโต๊ะ
   เลือกขอบเขตได้ว่าจะแก้ **โต๊ะนี้**, **ทั้งแถว** (ตามเลขหัวแถว 1–14) หรือ **ตัวที่ N ทุกแถว** — กดทีเดียวแก้ทั้งหมด
   ถ้าแถวมีช่องว่าง จะมีปุ่ม "เติมโต๊ะในช่องว่าง" ให้ด้วย
   กด **ออกจากแอดมิน** ที่มุมบนเพื่อกลับหน้าปกติ (ที่แก้ค้างไว้ยังอยู่ เปิด `?admin` ครั้งหน้าก็ทำต่อได้)
3. ทุกการแก้เป็นแค่ตัวอย่าง กด **✓ ตกลง** แล้วใส่รหัสแอดมิน → เว็บบันทึก `layout.json` ขึ้น GitHub ให้เอง
   Vercel deploy ใหม่อัตโนมัติ เพื่อนเห็นผังใหม่ในราว 1 นาที (กด **ยกเลิก** เพื่อย้อนกลับ)
4. ถ้ายังไม่ได้ตั้งค่าระบบบันทึก (ด้านล่าง) จะบันทึกไว้ในเครื่องแทน ใช้ **ดาวน์โหลด layout.json**
   แล้วอัปโหลดไปแทนไฟล์ใน GitHub เองก็ได้

ใครเปิด `?admin` ก็ได้ แต่จะบันทึกขึ้นเว็บได้ต้องรู้รหัสแอดมิน

## ตั้งค่าปุ่มบันทึกขึ้นเว็บ (ทำครั้งเดียว)

ปุ่ม ✓ ตกลง ส่งผังไปที่ `api/save-layout.js` (ฟังก์ชันบน Vercel) ซึ่งจะ commit `layout.json` ขึ้น GitHub
ต้องให้กุญแจกับรหัสแก่ Vercel ก่อน:

**1. สร้าง GitHub token (ให้เขียนได้เฉพาะ repo นี้)**

1. github.com → รูปโปรไฟล์มุมขวาบน → **Settings** → **Developer settings** (ล่างสุดของเมนูซ้าย)
2. **Personal access tokens → Fine-grained tokens → Generate new token**
3. Token name: `torim-save` · Expiration: เลือกตามสะดวก (เช่น 1 ปี)
4. Repository access: **Only select repositories** → เลือก `to_rim`
5. Permissions → Repository permissions → **Contents: Read and write**
6. กด **Generate token** แล้วคัดลอก token ที่ขึ้นต้นด้วย `github_pat_...` ไว้ (จะเห็นแค่ครั้งเดียว)

**2. ใส่ค่าใน Vercel**

1. vercel.com → เปิดโปรเจกต์ → **Settings → Environment Variables**
2. เพิ่ม 2 ตัว:
   - `GITHUB_TOKEN` = token จากข้อ 1
   - `ADMIN_PASSWORD` = รหัสแอดมินที่ตั้งเอง (ยาวๆ เดายาก)
3. ไปที่แท็บ **Deployments** → จุดสามจุดของอันล่าสุด → **Redeploy** (ค่าใหม่จะมีผลหลัง deploy ใหม่)

ไม่บังคับ: ถ้าย้าย repo ให้ตั้ง `GITHUB_REPO` (ค่าเริ่มต้น `pokemobb/to_rim`) และ `GITHUB_BRANCH` (ค่าเริ่มต้น `main`)

อย่าใส่ token หรือรหัสแอดมินลงในไฟล์ใดๆ ใน repo — ใส่ใน Vercel เท่านั้น

ขนาดห้อง ตำแหน่งร้านค้า/ประตู และระยะห่างโต๊ะ แก้ได้ใน `layout.json` โดยตรง (หน่วยเมตร)

- `walls` — แนวกำแพง (ประตูที่อยู่บนแนวกำแพงจะเว้นช่องให้เอง)
- `landmarks` — ของในฉาก ใส่ `kind` เป็น `shop` (ร้านค้า), `dishes` (ที่วางจาน), `toilet` (ห้องน้ำ),
  `door` (ประตู) หรือ `plant` (ต้นไม้) ปกติจะหันหน้าเข้าหากลางห้องเอง ถ้าอยากหมุนเองใส่ `"facing": 90` (องศา)
- หน้าตาของแต่ละแบบอยู่ใน `scenery.js`

## Deploy (GitHub + Vercel)

หน้าเว็บเป็นไฟล์ static ไม่มีขั้นตอน build (three.js โหลดจาก CDN) มีแค่ `api/save-layout.js` ที่รันเป็นฟังก์ชันบน Vercel

1. สร้าง repo ใหม่บน GitHub แล้ว push ไฟล์ในโฟลเดอร์นี้ขึ้นไป
2. ที่ vercel.com → **Add New → Project** → เลือก repo นั้น
3. Framework Preset เลือก **Other** ไม่ต้องตั้ง Build Command → กด Deploy
4. หลังจากนี้ push อะไรขึ้น GitHub ก็ deploy ใหม่ให้อัตโนมัติ

## เปิดดูในเครื่อง

ต้องเปิดผ่าน web server (ดับเบิลคลิกไฟล์ตรงๆ ไม่ได้ เพราะใช้ ES modules และโหลด layout.json)

```bash
python3 -m http.server 5173
```

แล้วเปิด http://localhost:5173 (ในเครื่องจะไม่มีระบบบันทึกขึ้นเว็บ ปุ่มตกลงจะบันทึกไว้ในเครื่องแทน)
